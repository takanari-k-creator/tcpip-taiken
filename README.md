# パケットを届けよう！ TCP/IP 体験シミュレータ

高校「情報Ⅰ」情報通信ネットワークの体験教材です。インストールは不要で、ブラウザで開くだけで使えます。

**使うページ：** https://takanari-k-creator.github.io/tcpip-taiken/

## 内容
1. **回線交換とパケット交換**：4台が同時に送ったときの完了時間を比べる
2. **プロトコルと4階層**：宅配便の伝票にたとえて、層ごとのヘッダが付く・外れる様子をアニメーションで見る
3. **TCPの体験**：メッセージをパケットに分割して送り、「約束なし」と「TCP（番号・ACK・再送）」を比べる
